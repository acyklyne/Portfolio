# **App Name**: Klyne's Canvas

## Core Features:

- Responsive Navigation Bar: Intuitive navigation with smooth transitions across different sections.
- Dynamic Projects Gallery: Visually engaging showcase of projects with interactive elements.
- 'About Me' Section: Detailed overview of skills, experience, and professional background.
- Social and Contact Links: Integrated links for easy access to social media profiles and contact information.
- Light/Dark Mode Toggle: Allow the user to switch between a light and dark color theme based on preference.

## Style Guidelines:

- Primary color: Vibrant teal (#008080) to give a sense of modern and interactive feel.
- Background color: Dark gray (#282828) for a sleek and professional look.
- Accent color: Light teal (#70dbdb) to complement the primary color with contrast and enhance focus.
- Body and headline font: 'Inter', a sans-serif font, will be used.
- Simple, modern icons to enhance usability and visual appeal.
- Clean, grid-based layout to ensure responsiveness and readability.
- Subtle animations and transitions to create a smooth user experience.
